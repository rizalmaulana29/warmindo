06

Rekomendasi Sebelum Migrasi

  • Extend partisi di warehouse. ±310 GB sisa disk belum dipartisi — perlu di-extend supaya bisa dipakai database.
  • Pantau partisi root di monix-cjr yang sudah 84% — pertimbangkan perbesar sebelum data Odoo bertambah banyak saat migrasi.
  • Konfirmasi peran baim-cjr. Apakah memang disiapkan menampung container Docker dari server lama (notification_service, n8n, dll)? Kalau iya, ini kandidat paling pas — Docker sudah ada & RAM longgar.
  • Cek apakah warehouse ini pengganti DB_WAREHOUSE_HOST milik notification_service di server lama, supaya koneksinya bisa diarahkan ke sini.
  • Rencanakan resize partisi dengan hati-hati karena tidak ada satupun VM yang memakai LVM — butuh tools seperti growpart/resize2fs, idealnya lewat provider VM/hypervisor dulu untuk memperbesar disk virtualnya.
